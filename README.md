## Planned features
- [x] Textfile (.txt)
- [x] Markdown (.md) using `gpt_markdown` library
- [x] Drawing / Whiteboard
- [x] Tables using `pluto_grid` library
- [ ] CSV file support
- [ ] NotDwn language and support with embedded images
- [ ] Charts
- [ ] Knowledge graph
- [ ] Android editors
- [ ] User themes
